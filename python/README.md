# byobot

an open source personal health operating system. you own all your own data locally. bring any agent.

This package is byobot's core: the local store, the `byobot` CLI, the MCP server (`byobot mcp`) and LAN sync with the iPhone app (`byobot serve`).

```bash
byobot init
byobot mcp
```

Pre-alpha. Docs and source: https://github.com/byobot/byobot

Apache-2.0.
